## 📖 About the Project

**Peak Trails** is a modern, responsive tourism website dedicated to hiking adventures in the Ukrainian Carpathian Mountains.

The project was developed as part of a front-end development learning experience at **Logika School**.

The website provides information about hiking destinations, available routes, travel experiences, and tour booking opportunities.

## ✨ Features

- 🏔️ **Hiking Routes** — Explore destinations across the Carpathian Mountains.
- 📱 **Responsive Design** — Layout designed for different screen sizes.
- 🌍 **Multilingual Support** — Ukrainian, English, Slovak, and Italian.
- 📝 **Booking Form** — Interactive form with JavaScript validation.
- ✅ **Real-Time Validation** — Checks names, phone numbers, and selected routes.
- 🎨 **Modern UI** — Clean design, photography, and intuitive navigation.
- 📄 **Multiple Pages** — Home, hiking routes, and About Us.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/sneaky91/Logika_front_end_project.git
```

Navigate to the project directory:

```bash
cd Logika_front_end_project
```

Open `index.html` in your web browser.

No additional dependencies or installation steps are required.

## 📋 Form Validation

The booking form includes client-side validation using JavaScript.

- Full name validation
- Ukrainian phone number format verification
- Route input validation
- Real-time error messages
- Visual feedback for valid and invalid fields

**Note:** The booking form currently performs client-side validation and displays a confirmation message. It does not send booking requests to a backend server.
